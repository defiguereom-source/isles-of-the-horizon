# Isles of the Horizon

> Un juego de aventura top-down inspirado en el clásico *The Legend of Zelda* (NES, 1986).

**Versión 1.0** · Proyecto personal · Español

---

## 📖 Sobre el proyecto

Este es un proyecto personal desarrollado con el objetivo de recrear la esencia de las aventuras clásicas de acción top-down: exploración, combate directo, gestión de inventario e interacción con NPCs.

El juego fue construido desde cero utilizando **C#** y el motor **Unity**, apoyándome en assets gratuitos para el entorno y contando con la colaboración de una artista que se encargó del diseño y arte de los NPCs.

## 🕹️ Controles

| Tecla | Acción |
|:-----:|--------|
| `W` `A` `S` `D` | Movimiento del personaje |
| `J` | Atacar |
| `I` | Abrir / cerrar inventario |
| `F` | Interactuar con NPCs |
| `ESC` | Salir al menú principal |

> 💡 El juego está completamente en **español**.

---

## ✨ Características

-  **Combate en tiempo real** con sistema de ataque cuerpo a cuerpo
-  **Sistema de inventario** para gestionar objetos recogidos durante la aventura
-  **NPCs interactivos** con diálogos y arte original
-  **Exploración libre** de mapas al estilo top-down clásico
-  **Estética retro** inspirada en la era de los 8/16 bits

## 🚀 Instalación y ejecución

### Jugar la versión compilada

1. Descarga el juego desde [itch.io](https://tu-usuario.itch.io/tu-juego)
2. Descomprime el archivo
3. Ejecuta el `.exe`

### Abrir el proyecto en Unity

```bash
git clone https://github.com/defiguereom-source/isles-of-the-horizon/tree/main/Assets
```

1. Abre **Unity Hub**
2. Selecciona `Add` → elige la carpeta del proyecto
3. Ábrelo con la versión de Unity **Unity6.6**
4. Carga la escena principal desde `Assets/Scenes/`

## 🗂️ Estructura del proyecto

```

├── Scripts/        # Lógica en C#
├── Prefabs/        # Objetos reutilizables
```
